# Porting notes for kiosk-app v1.6.0

- Ownership: purchases and extra payments live in the **order service** (they are money next to
  the orders; extra payments are booked in the same transaction as the settlement). The store
  balance is computed by the **report service** over `GET /internal/money/*` and
  `/internal/orders/export`, like the other reports. Payment info lives in the **settings service**.
- Deviation: the monolith stores uploaded payment QR codes as files next to the product images.
  Here they are rows in the settings database (table `payment_qr`) and served by the settings
  service at `/api/images/pay-<32 hex>.<ext>`; the gateway route table has an extra, longer prefix
  `/api/images/pay-` (nginx `^~` picks the longest prefix). This avoids a second volume and keeps
  the images in the Postgres backup, and the frontend needs no change.
- New tables (`purchases`, `extra_payments`, `payment_qr`) are created by `create_all`; no
  existing table changed, so no `ALTER TABLE` was needed.
- Not ported: the monolith's `tests/e2e` (Playwright) changes; this repo has no browser tests.
